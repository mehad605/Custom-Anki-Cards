# ✨ Custom Anki Card Types

Enhance your Anki learning experience with beautiful, modern card templates featuring Markdown support, Catppuccin themes, and advanced layout types.

## 🚀 Features

- 🎨 **Catppuccin Style**: Gorgeous, eye-friendly color palette applied to the cards and code blocks.
- 📝 **Markdown Support**: Render Markdown directly in your cards for better formatting.
- 💻 **Syntax Highlighting**: Beautiful code blocks powered by the Catppuccin theme.
- 🧩 **Advanced Types**: Go beyond standard flashcards with templates for Matching, Ordering, and Multiple Choice.
- 📖 **Self-Documenting**: Each card type comes with an example that demonstrates exactly how to fill in the fields.

## 🛠️ How to Use

The easiest way to get these into Anki is using the pre-packaged `.apkg` files.

1.  **Download**: Head over to the [GitHub Releases](https://github.com/mehad605/Custom-Anki-Cards/releases) section.
2.  **Choose your pack**:
    *   Download `ALL_IN_ONE.apkg` to get every card type at once.
    *   Alternatively, download the specific `.apkg` for the card type you want.
3.  **Import**:
    *   Open Anki.
    *   Go to `File` -> `Import`.
    *   Select the `.apkg` file you downloaded.
4.  **Done!**: The card types will now be available when you create a new card.

> [!TIP]
> **Not sure how to format the fields?**
> After importing, look at the sample cards provided. They serve as live documentation, showing you exactly how to write in the fields to make the interactive features work perfectly.
